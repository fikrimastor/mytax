# Milestone 8 — Expanded YA 2025 relief registry

Primary source: https://www.hasil.gov.my/individu/pelepasan-cukai/

A 2025-only read-only registry now enumerates individual, family, child, medical, education, lifestyle, insurance, savings, disability and first-home categories. Values are maximum category ceilings, **NOT entitlements**.

Every entry is DRAFT_REVIEW_REQUIRED. Nested entries show only a **subset** of shared limits. Mutually exclusive tiers (e.g. first-home interest, child education) must never be added together. EPF/life insurance has component caps not yet represented. No automatic deductions or filing result is generated by this registry.
