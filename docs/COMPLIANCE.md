# Compliance acceptance gates

A tax rule cannot be activated without:
1. Assessment year, statutory effective date, and relevant legal conditions.
2. Primary official source URL, capture date, snapshot hash and paragraph citations.
3. Approval by a qualified Malaysian tax reviewer.
4. Boundary, nested-cap, evidence, spouse/child eligibility tests as relevant.
5. Reconciliation with official LHDN examples or independently verified calculations.
6. Immutable policy release so historical calculations are reproducible.

Rule lifecycle: DRAFT -> REVIEW -> APPROVED -> ACTIVE -> SUPERSEDED.

An internal approval is **not** an LHDN endorsement.

Official starting sources:
- https://www.hasil.gov.my/individu/pelepasan-cukai/
- https://www.hasil.gov.my/individu/kadar-cukai/
- https://mytax.hasil.gov.my/

No statutory relief limits or tax calculations are activated in this starter. Never treat AI-generated categories as legal determinations.
